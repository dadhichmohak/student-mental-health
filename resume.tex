\section{Projects}

\project{Student Mental Health Predictor}{Jan 2025 -- Present}
\hfill \faGithub \href{https://github.com/dadhichmohak/student-mental-health}{dadhichmohak/student-mental-health}

\begin{itemize}[leftmargin=*, nosep, itemsep=4pt]

  \item \textbf{Situation:} Student mental health datasets are limited in scope (ages 18--24, narrow sleep/screen ranges), making models brittle to real-world edge cases.
  \textbf{Task:} Build a predictive web application that estimates a student's mental health score (0--10) from social media habits, academic workload, and daily routine.
  \textbf{Action:} Trained and compared 6 regression models (Linear, Ridge, Decision Tree, Random Forest, Gradient Boosting, Extra Trees); engineered 5 interaction features (Screen--Sleep Ratio, Lifestyle Balance, etc.); augmented training data with 500 synthetic extreme cases to extend input ranges.
  \textbf{Result:} Selected Gradient Boosting (R$^2$=0.893, MAE=0.341) with 3.8\,MB model size and $\sim$10\,ms prediction latency --- 43$\times$ faster than the best alternative.

  \item \textbf{Situation:} ML demos typically rely on Streamlit or Gradio, limiting UI customizability and learning opportunity.
  \textbf{Task:} Deploy the trained model into a fully custom web frontend without ML-specific frameworks.
  \textbf{Action:} Built a vanilla HTML/CSS/JS frontend with animated SVG gauge visualization, client-side validation mirroring Pydantic checks, and a 4-band signal legend (Strained/Moderate/Balanced/Strong); connected to a FastAPI backend serving a single \texttt{/predict} REST endpoint.
  \textbf{Result:} End-to-end pipeline from raw form input to model prediction in $<$100\,ms round-trip; responsive UI working across desktop and mobile.

  \item \textbf{Situation:} The original dataset had 111 unique countries, high-cardinality categoricals, and skewed numeric distributions degrading model performance.
  \textbf{Task:} Clean and preprocess the data to maximize model accuracy while keeping the inference pipeline lightweight for web deployment.
  \textbf{Action:} Applied country grouping (top 10 + Other), log transforms for skewed features, ordinal encoding for stress levels, and one-hot encoding for categoricals inside a single scikit-learn \texttt{Pipeline}; serialized the full pipeline with joblib.
  \textbf{Result:} Reduced model size from 67.5\,MB (Extra Trees) to 3.8\,MB (Gradient Boosting) with minimal accuracy loss; single-file deployment (\texttt{.pkl}) simplifies backend setup.

\end{itemize}

\vspace{4pt}
\noindent\textbf{Tech Stack:} Python, scikit-learn, FastAPI, Pydantic, joblib, vanilla JavaScript, SVG, CSS3
